# Movie-Rating-Prediction-with-Python

1) Project Overview

- Movie Rating Prediction is a machine learning project that predicts the IMDb rating of a movie based on features such as genre, director, actors, year, and duration.
The project demonstrates a complete data science workflow, including data preprocessing, feature engineering, visualization, model building, and evaluation.

- This project helps analyze factors that influence movie ratings and builds a regression model to estimate ratings accurately.

2) Objective

- Analyze historical movie data

- Understand relationships between movie attributes and ratings

- Build a regression model to predict movie ratings

- Visualize data insights and model performance

3) Dataset

IMDb Movies India Dataset

Target Variable

- Rating

Features Used

- Genre

- Director

- Actor 1

- Actor 2

- Actor 3

- Year

- Duration

4) Technologies Used

- Python

- Pandas & NumPy – Data manipulation

- Matplotlib & Seaborn – Data visualization

- Scikit-learn – Machine learning and evaluation

5) Project Workflow

- Data Loading

- Data Cleaning & Preprocessing

- Feature Engineering

- Exploratory Data Analysis (EDA)

- Feature Encoding

- Model Training (Regression)

- Model Evaluation

- Visualization & Insights

6) Data Visualizations

The project includes multiple visualizations to gain insights:

- Distribution of movie ratings

- Average rating by genre

- Movie duration vs rating

- Ratings trend over the years

- Feature importance from the model

- Actual vs predicted ratings

These visualizations help interpret both the dataset and the model’s performance.

7) Machine Learning Model

- Algorithm Used: Random Forest Regressor

- Reason: Handles non-linear relationships and categorical features effectively

8) Model Evaluation Metrics

- Mean Absolute Error (MAE)

- Root Mean Squared Error (RMSE)

- R² Score

These metrics help assess prediction accuracy and model reliability.
